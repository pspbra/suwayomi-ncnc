# Getting Started with Create React App

This project is built with [Vite](https://vitejs.dev/)

## Available Scripts

In the project directory, you can run:

### `pnpm dev`

This command runs the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page reloads when you make edits.\
Lint errors also appear in the console.

### `pnpm preview`

This command runs the app in a local preview production build.

### `pnpm build`

This command creates an optimized production build of the app and places it in the `build` folder.

Deploy the entire contents of `build`, including the `revision` file next to `index.html`.
Suwayomi-Server reads this file to report the WebUI version. It is now generated by Vite,
so manually zipped builds include it as well. Set `WEBUI_REVISION` to supply a known build
revision; otherwise Git checkouts use their commit count (`r<number>`), and source archives
without Git history use `r0` to identify an unversioned local build.

### Startup authentication regression test

With the production preview running and Playwright available, run
`node tools/scripts/tests/startup-auth.mjs`. If Playwright is installed elsewhere, set
`PLAYWRIGHT_MODULE` to its absolute `index.mjs` path. `TEST_BASE_URL` defaults to
`http://127.0.0.1:4173/` and `BROWSER_CHANNEL` defaults to `msedge`.
The test mocks all GraphQL requests, including successful login, rejected login, token
refresh, and missing WebUI version information. It does not use a real account.
See this section about [Building for Production](https://vitejs.dev/guide/build.html) for more information.
